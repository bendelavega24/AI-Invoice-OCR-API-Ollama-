# Modern Enterprise UI release — November 5, 2026

## What changed

This is a **presentation-layer-only** modernization of the October 30 HybridSearch
application. It retains Streamlit 1.38, the existing multipage architecture,
OCR/TrOCR extraction, Groq/Ollama provider behavior, SQLite models/migrations,
hybrid AI Search, field evidence, history verification and export logic.

| Area | Change |
| --- | --- |
| Shared UI | New `ui/components/design_system.py` with one palette, typography, native-control styling, accessible page headings and a responsive layout |
| Navigation | Dark navy sidebar with clear sections and preserved upload-locking and role-based navigation |
| Sign-in | Clean sign-in and mandatory password-change headings; no authentication changes |
| Home | Branded summary, metrics including totals separated by currency, and page shortcuts |
| Dashboard | Modern KPI tiles, two-column charts and monthly spending card; all currency filters retained |
| Upload | Consistent header and one-invoice-per-file guidance; original form and processing path unchanged |
| History | Consistent page header, improved data-table styling and search hierarchy |
| Reports / Log | Consistent page headers, improved HTML table appearance and search hierarchy |
| Users | Consistent administration page; account actions untouched |
| `.streamlit/config.toml` | Light app canvas with blue accents; no new dependency or unsupported sidebar-theme configuration |

## Preserved behaviors

- AI mode and model selector, browser-session login, upload navigation lock.
- Hybrid natural-language search (local parser + optional LLM interpretation).
- Conditional vision model availability checks and upload result handling.
- Currency-separated Dashboard, History and Reports totals.
- Original DB schema, query code, invoice extraction and exports.
- All verification highlights and client-approved field visibility.
- Page and control keys used by existing Streamlit sessions; no deliberate
  key changes in Upload, History, Reports, Log, or Users.

## How to install

1. Back up your active installation, `.env`, `data`, and `storage` directories.
2. Extract this source ZIP to a separate QA folder.
3. Copy only your private `.env` and, if required for testing, **copies** of your
   existing database and invoice storage into that QA directory.
4. Activate your existing compatible Python environment; install dependencies
   only if required using `pip install -r requirements.txt`.
5. Run `python app.py ui` or use the existing `start_server.bat`.
6. Check Login, Home, Upload, Dashboard, History, Reports, Log and Users.

The stylesheet uses CSS selectors supported by the current Streamlit UI.
If a future Streamlit version changes its HTML layout, native widgets remain
functional, but some styling may need updating.

## Visual QA checklist (Windows desktop)

- Sign in and sign out; verify mandatory password-change flow if available.
- Confirm selected page navigation remains clear and upload locks other pages.
- Open desktop and narrower browser windows; confirm no clipped labels or buttons.
- Test invoice upload, error notice, duplication, OCR review and History image viewer.
- Confirm amber verification highlights and edit controls remain readable.
- Test PHP and USD invoices together; amounts must remain separate.
- Test AI Search, report exports, log searches, and user-management actions.
- Confirm print/PDF exports use the original report design (not injected sidebar
  styles). Actual extracted invoice data should be unchanged.

## Testing limitations

Python syntax and source-level regression tests can be run without the
Streamlit runtime. Full browser and live Groq/Ollama acceptance tests must be
performed on the actual Windows installation; this release does not claim
they have already passed.

## Rollback

Restore the previous October 30 source ZIP. Preserve the backed-up `.env`,
database and storage. No database migration was added by this UI update.
